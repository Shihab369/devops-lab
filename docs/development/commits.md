# Commit Conventions

Use focused Conventional Commit-style messages.

## Common Types

```text
feat:     new functionality
fix:      bug fix
test:     test changes
docs:     documentation
refactor: code restructuring
ci:       CI changes
```

## Examples

```text
feat: add network diagnostics
fix: handle empty network address lists
test: add network collector coverage
docs: update collector documentation
ci: add Go workflow
```

## Avoid

```text
update
changes
stuff
final
fix
test
```

A commit message should describe the change clearly.

Keep commits focused. Avoid mixing unrelated changes.
